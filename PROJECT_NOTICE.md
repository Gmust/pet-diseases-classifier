# Smart Pet Care App — Project Notice

This repository is a component of the **Smart Pet Care App** collaborative student project.
It contains the AI microservice of the project (classifier and related AI functionality).

The Smart Pet Care App project consists of a mobile client, a backend API, an AI microservice,
designs, project management materials and project documentation. Materials belonging to the
project are not limited to this repository.

## Canonical project agreement

The canonical project agreement, contributor list and component list are maintained with the
Smart Pet Care App project documentation, in the canonical project repository:

https://github.com/Gmust/smart-pet-care-app

- `PROJECT_AGREEMENT.md` — authorship and internal project usage terms
- `PROJECT_COMPONENTS.md` — the components that make up the project
- `CONTRIBUTORS.md` — contributors, based on repository history

There is only one project agreement. This repository does not define separate or differing
terms. If a copy of the Agreement is ever placed in this repository, it must be clearly marked
as a copy, and the canonical version above prevails.

## Acceptance

This notice does not by itself imply that every historical Contributor has accepted the project
agreement. Contributor acceptance is recorded separately, in the Acceptance section of the
canonical `PROJECT_AGREEMENT.md`.
